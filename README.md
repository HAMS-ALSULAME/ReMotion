# ReMotion

ReMotion is a SportsTech prototype developed to explore an innovative approach to injury prevention and rehabilitation.

The concept combines a smart shin guard equipped with sensors and AI-based insights to help athletes monitor their recovery and rehabilitation progress.

## Prototype Features
- Smart shin guard concept with integrated sensors
- Injury prevention and rehabilitation monitoring
- Recovery progress tracking
- Symmetry, load, and stability insights
- Personalized rehabilitation plan
- Expected return-to-play insights

## Prototype Application
An initial application prototype was designed to demonstrate the ReMotion user experience, including injury selection, rehabilitation plans, live sessions, and recovery insights.

## Technologies & Concepts
- Artificial Intelligence (AI)
- Wearable Sensors
- Sports Technology
- UI/UX Design
- Data Monitoring and Analysis

## Project Context
ReMotion was developed as part of SEU Velocity, a Sports Technology Challenge organized by the Business Hub at Saudi Electronic University.

The project was developed as an initial prototype to demonstrate the proposed solution and user experience.
